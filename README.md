## Building AINCRAFT

Floating floors, quiet towns and adventures beyond the gates. AINCRAFT brings the world of Aincrad into Minecraft, with a focus on the atmosphere and sense of adventure that make SAO memorable.

I'm developing the world alongside a dedicated Windows launcher that makes getting started simple. The project is still taking shape, and the launcher is available now.
